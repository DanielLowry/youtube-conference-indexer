# Interface fonts

Geist and JetBrains Mono, Latin variable WOFF2 subsets, downloaded from the
Google Fonts CSS API on 18 October 2026. Hosted locally to avoid runtime font
requests to external services. Unicode outside these subsets uses system fallbacks.

- Geist: https://fonts.google.com/specimen/Geist
- JetBrains Mono: https://fonts.google.com/specimen/JetBrains+Mono
- Licenses: `geist-OFL.txt`, `jetbrains-mono-OFL.txt` (SIL Open Font License 1.1).
