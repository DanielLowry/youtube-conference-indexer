YouTube Conference Indexer

How to use this app

  1. Set a valid YouTube API key on the API Key page.
  2. Add sources on Sources (channel names/handles are OK; we’ll resolve the ID).
  3. For channel sources, click “Discover Playlists” and pin the ones you care about.
  4. Return here and click Sync Pinned Playlists to pull videos into your local database.
  5. Use Search to find videos (searches titles/descriptions of synced videos).
  6. Update status/notes/tags on videos; use Export (CSV/Markdown) to download filtered lists. In-memory mode loses data on restart.

Tip: If you see no search results or empty exports, ensure playlists are pinned and a sync has completed.
